# NIGHTSHIFT // Pure Body Protocol
8-week V-taper workout tracker. Static site, no build step. Data lives in the browser (localStorage).

## Deploy on Vercel
- CLI: `npm i -g vercel && vercel --prod` (run in this folder; framework preset "Other", no build command, output dir = root)
- or push to GitHub and import the repo at vercel.com/new

## Notes
- Set your start date in SYSTEM; phase, weekly targets and drop-set reminders follow it.
- Data is per browser/device. Use SYSTEM > EXPORT for backups.
